LumaBar 0.6 将自动明暗与可调玻璃任务栏整合在一个托盘程序中：桌面和普通窗口跟随壁纸，最大化 / 全屏窗口跟随应用明暗。

## 本次更新（相对 0.4）

- 集成 TranslucentTB 2026.2 的原生材质组件，支持透明、模糊、亚克力、纯色与系统默认外观，无需另开 TranslucentTB。
- 桌面、普通窗口、最大化分别设置材质、颜色、染色不透明度、模糊强度和顶部分隔线，提供预设及临时预览。
- 优先分析任务栏所在区域的壁纸；复杂背景按需要临时增强染色，保留用户保存的透明度。
- 事件触发快速检测；灵敏 / 均衡模式场景确认参数为 80 / 100 ms。任务栏优先刷新，其他窗口通知改到后台，保留内容防闪烁策略。
- 协调系统明暗与材质场景确认，丢弃过期外观请求，减少切换错色。
- 主界面显示场景、判断依据与各屏外观状态；组件失败时尝试降级为原生材质，自动明暗继续，支持一键重试。
- 各屏可以独立配置材质与染色，并按各屏壁纸增强可读性；Windows 图标文字明暗仍为全局共享。
- 暂停、退出和异常退出恢复得到加强；材质恢复失败时仍尝试恢复系统主题，并明确提示未确认的恢复。

## 下载与升级

1. 普通使用下载 **LumaBar-0.6-preview-x64.zip**，完整解压到固定可写目录。
2. 升级前从旧版托盘选择“退出并恢复”，退出独立 TranslucentTB，再启动新目录中的 LumaBar.exe。
3. 如需保留原配置，在旧版退出后将其 settings.json 复制到新目录。旧标准速度预设会自动迁移，已有应用规则和外观参数保留。
4. 如已开启开机自启，在新版本设置中保存自启选项以更新程序路径。

**LumaBar-0.6-source.zip** 提供整合版对应源码、构建脚本和固定版本 TranslucentTB 源码。GitHub 自动生成的 Source code 附件不包含展开的子模块。SHA256SUMS.txt 提供两个发布 ZIP 的校验值。
